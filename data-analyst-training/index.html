Module 1: Data Basics

Data kya hota hai aur usse kaise samjhein

1.1 — Data Kya Hai?

Definition: Data matlab koi bhi information jo hum collect karte hain — numbers, words, dates, ya facts ke roop mein.

🌍 Real Life mein Data:

Phone Usage

Har din kitne hours phone use karte ho — ye data hai!

Shopping

Kitna paisa kharcha kiya, kya kharida — ye bhi data hai!

Weather

Temperature, humidity, rain — ye sab data hai!

Cricket

Runs, wickets, strike rate — ye sports data hai!

🎯 Key Point:

Data Analyst ye data dekhta hai, patterns dhundhta hai, aur smart decisions lene mein help karta hai.

Jaise: "Sunday ko sabse zyada samosa bikta hai" → toh Sunday ko extra banao!

2.2 — Basic Formulas (SUM, AVERAGE, COUNT)

Excel ki taakat Formulas mein hai. Chalo sikhte hain:

=SUM()

=COUNT()

Kitne numbers hain count karta hai

=MAX() / =MIN()

Sabse bada / chhota number

2.3 — IF Formula (Conditions)

=IF() formula se hum conditions check karte hain — agar ye hai toh ye karo, warna wo karo.

Examples:

Discount dena hai?
=IF(D2>1000, "10% Off", "No Discount") Agar price 1000+ hai toh discount do

Module 3: Statistics Basics

Numbers ko samajhne ka science

3.1 — Mean, Median, Mode

Ye teen cheezein data ko summarize karti hain:

📐 Mean (Average)

Sabko jodo aur count se divide karo

Data: 10, 20, 30 → Mean = 60÷3 = 20
📏 Median (Middle Value)

Data ko sort karo, beech wala number lo

Data: 10, 20, 30 → Median = 20
🔄 Mode (Most Common)

Jo number sabse zyada baar aaye

Data: 10, 20, 20, 30 → Mode = 20

🧠 Quiz: Data: 5, 10, 15, 20, 25 — Mean kya hai?

3.2 — Range & Standard Deviation

📏 Range

Sabse bada - Sabse chhota = Range

Data: 10, 20, 50 → Range = 50-10 = 40
📊 Standard Deviation

Data kitna spread hai mean se

Low SD = Data close to mean
High SD = Data spread out
Socho: 2 classes ke marks hain. Dono ka average 70 hai. Lekin ek class mein sab 65-75 ke beech hain (Low SD), doosri mein 30-100 ke beech (High SD). Average same hai, par data bahut alag hai!

3.3 — Percentage & Ratios

📊 Percentage:

Percentage = (Part ÷ Total) × 100

Example: 85 marks out of 100 = (85÷100)×100 = 85%

📐 Growth Rate:

Growth = ((New - Old) ÷ Old) × 100

Example: Last month sales ₹10,000, this month ₹15,000

Growth = ((15000-10000)÷10000)×100 = 50% growth!

🧠 Quiz: 45 out of 60 students pass. Pass percentage?

3.4 — Correlation (Connection between data)

Correlation = Kya 2 cheezein ek saath badhti/ghatati hain?
📈 Positive Correlation

Ek badhta hai toh doosra bhi badhta hai

Study hours ↑ = Marks ↑
📉 Negative Correlation

Ek badhta hai toh doosra ghatta hai

Phone use ↑ = Sleep ↓
🔄 No Correlation

Dono mein koi connection nahi

Shoe size ↔ Marks = No link

3.5 — Outliers (Unusual Data Points)

Outlier = Jo data baaki se bahut alag ho. Ye galat ho sakta hai ya interesting ho sakta hai!

Example: Class marks: 70, 75, 80, 72, 78, 15, 82

Yahan 15 ek outlier hai — baaki sab 70+ hain!

Outlier ka kya karein?

  • Check karo: Kya ye data entry mistake hai?
  • Investigate karo: Shayad kuch real reason hai (student beemar tha)
  • Decide karo: Analysis mein rakhein ya hatayein?

Module 4: SQL Basics

Database se data nikalna sikhna

4.1 — SQL Kya Hai? SELECT Statement

SQL (Structured Query Language) = Database se data maangne ki language. Jaise Google pe search karte ho, waise database pe SQL likhte ho!

Basic SELECT:

-- Sab students ka data dikhao
SELECT * FROM students;

-- Sirf name aur marks dikhao  
SELECT name, marks FROM students;

-- Sirf top 5 dikhao
SELECT * FROM students LIMIT 5;

🎯 Yaad Rakho:

  • SELECT = Kya chahiye
  • FROM = Kahan se chahiye
  • * = Sab kuch chahiye

4.2 — WHERE (Filtering Data)

WHERE se hum condition lagaate hain — sirf wahi data dikhta hai jo condition match kare.

-- 80+ marks wale students
SELECT * FROM students WHERE marks > 80;

-- Mumbai ke students
SELECT * FROM students WHERE city = 'Mumbai';

-- Pass students (marks >= 40) jo Delhi se hain
SELECT * FROM students 
WHERE marks >= 40 AND city = 'Delhi';

🧠 Quiz: "Sirf 90+ marks wale dikhao" ke liye kya likhenge?

4.3 — GROUP BY & Aggregate Functions

GROUP BY se data ko groups mein todke calculations karte hain:

-- Har city mein kitne students hain?
SELECT city, COUNT(*) as total_students
FROM students
GROUP BY city;

-- Har city ka average marks?
SELECT city, AVG(marks) as avg_marks
FROM students
GROUP BY city;

-- Results ko sort karo
SELECT city, AVG(marks) as avg_marks
FROM students
GROUP BY city
ORDER BY avg_marks DESC;

SQL Aggregate Functions:

  • COUNT() - Kitne hain
  • SUM() - Total
  • AVG() - Average
  • MAX() - Sabse bada
  • MIN() - Sabse chhota

4.4 — JOIN (Tables ko jodna)

Real world mein data alag-alag tables mein hota hai. JOIN se hum 2 tables ko jodte hain! 
-- Students table + Marks table ko jodo
SELECT students.name, marks.subject, marks.score
FROM students
JOIN marks ON students.id = marks.student_id;

-- LEFT JOIN: Sab students dikhao, marks na ho toh bhi
SELECT students.name, marks.score
FROM students
LEFT JOIN marks ON students.id = marks.student_id;

5.2 — Lists & Loops

# List banana
marks = [85, 90, 78, 92, 88]

# List ke operations
print("Total students:", len(marks))
print("Highest:", max(marks))
print("Lowest:", min(marks))
print("Average:", sum(marks)/len(marks))

# Loop: Har student ka marks print karo
for m in marks:
    if m >= 80:
        print(m, "- Excellent! 🌟")
    else:
        print(m, "- Good 👍")

5.3 — Pandas (Data Analysis Library)

Pandas Python ki sabse important library hai data analysis ke liye. Ye Excel jaisa kaam karta hai, lekin zyada powerful! 
import pandas as pd

# CSV file read karo
df = pd.read_csv("students.csv")

# Data dekho
print(df.head())        # Top 5 rows
print(df.shape)         # Kitni rows & columns
print(df.describe())    # Statistics summary

# Filtering
top_students = df[df['marks'] > 80]
print(top_students)

# Group by
city_avg = df.groupby('city')['marks'].mean()
print(city_avg)

5.4 — Data Visualization with Matplotlib

import matplotlib.pyplot as plt

# Bar Chart
subjects = ['Math', 'Science', 'English', 'Hindi']
marks = [85, 92, 78, 88]

plt.bar(subjects, marks, color=['#6366f1','#10b981','#f59e0b','#ef4444'])
plt.title('Subject wise Marks')
plt.xlabel('Subject')
plt.ylabel('Marks')
plt.show()

# Pie Chart
plt.pie(marks, labels=subjects, autopct='%1.1f%%')
plt.title('Marks Distribution')
plt.show()

# Line Chart
months = ['Jan','Feb','Mar','Apr','May']
sales = [100, 150, 130, 170, 200]
plt.plot(months, sales, marker='o', color='#6366f1')
plt.title('Monthly Sales')
plt.show()
